# Siddheshwar Solar — Website V1

A Next.js starter for Siddheshwar Solar, designed around the "From Sun to Socket" idea rather than a generic SaaS/AI aesthetic.

## Visual direction
- Deep navy -> amber dusk/sunrise palette
- Industrial/engineering typography and spacing
- Real installation photography as the primary visual language
- Minimal card-grid usage; emphasis on full-width sections, editorial layouts and project photography
- Mobile responsive

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
- Contact form is a temporary mailto implementation. The next version should post to the Spring Boot API.
